Pebble Games

All games

A pebble is a value held in memory. Pebble games are a standard way to reason about how memory, time and energy trade off in computation. Each game adds one constraint that matters in real machines. New here? Start with Reversible.

Reversible

Erasing information costs heat. Uncomputing avoids erasure, but needs extra memory, which can be traded for extra time.

Bennett, SIAM J. Comput. 1989 · Knill, arXiv:math/9508218

Clean finish

The same game, but a reversible computer can't leave scratch work behind. Ending with only the answer costs extra moves or extra memory.

Bennett, SIAM J. Comput. 1989 · Knill, arXiv:math/9508218

Erasure

At finite speed, reversible steps cost energy too, so erasing a saved state is sometimes the cheaper choice. This game asks when.

Thumann & Soloveichik, arXiv:2610.24435

Spooky

A quantum computer can measure a qubit away instead of uncomputing it, leaving a phase to fix later. That trades qubits for time.

Gidney, blog post, 2019 · Kornerup, Sadun & Soloveichik, Quantum 2025, arXiv:2110.08973

DAG

Real computations branch. Deciding how few pebbles a reversible computation on a general graph needs is PSPACE-complete.

Chan, Lauria, Nordström & Vinyals, FOCS 2015, arXiv:2305.19104

Red-blue

Fast memory is small, so moving data between memory levels, not arithmetic, is often the real cost.
